# 🎵 Spotify Clone

A responsive **Spotify Clone** built using **HTML, CSS, and JavaScript**. This project recreates the look and basic functionality of Spotify with a clean and user-friendly interface.

## 🚀 Features

- 🎧 Spotify-inspired user interface
- ▶️ Play and pause music
- ⏭️ Next and previous song controls
- 🎚️ Music progress bar
- 📱 Responsive design
- 🎵 Song playlist
- 🔊 Music player controls
- 💻 Built completely with frontend technologies

## 🛠️ Technologies Used

- **HTML5** – Structure of the website
- **CSS3** – Styling and responsive layout
- **JavaScript** – Music player functionality and interactions

## 📂 Project Structure

spotify-clone/

## 🎯 Purpose

This project was created to practice **frontend web development**, including HTML structure, CSS styling, JavaScript DOM manipulation, event handling, and audio player functionality.
